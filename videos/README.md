# WhatsApp Events videos

The WhatsApp Events case study (`#/whatsapp`) shows a placeholder for each screen recording until its file exists here.
Drop in MP4s with these exact names and they appear automatically, muted and looping:

| File | Section | Shape |
|---|---|---|
| `whatsapp-new-event.mp4` | Start an event | Phone, 328×710 |
| `whatsapp-time-location.mp4` | Time and location | Phone, 328×710 |
| `whatsapp-tasks.mp4` | Tasks | Phone, 328×710 |
| `whatsapp-payments.mp4` | Payments (adding an expense) | Phone, 328×710 |
| `whatsapp-settle-up.mp4` | Payments (settling up) | Phone, 328×710 |
| `whatsapp-rsvp.mp4` | RSVP | Landscape, 580×417 |

Keep each one short and small (H.264, no audio, under ~3 MB).
